# FTP Storage Panes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** FTP/FTPS servers open as storage panes (browse, transfer, rename, compare) through a patched copy of OpenDAL's FTP service, with WebDAV's certificate trust.

**Architecture:** OpenDAL's `opendal-service-ftp` 0.59.5 (Apache-2.0) is copied into `src-tauri/src/storage/ftp/` and patched (injected TLS config, MLSD/`LIST -a`, symlinks, temp uploads beside the target, shared 2-connection pool per account, no folder creation). Accounts gain provider `ftp`; `remote_for` builds the patched service; `Remote` gains an FTP target for rename. The web form, picker and trust flow reuse WebDAV's.

**Tech Stack:** Rust (Tauri v2, opendal 0.59.5 raw API, suppaftp 10 with `tokio-rustls-ring`, asyncband pool, rustls 0.23/ring), React 19, vitest.

**Spec:** `docs/superpowers/specs/2026-11-20-ftp-design.md`

## Global Constraints

- One rustls provider (ring): `cargo tree -i aws-lc-rs` prints nothing; no `rustls-native-certs`.
- The copied files keep an `// Derived from Apache OpenDAL opendal-service-ftp 0.59.5 (Apache-2.0); changed by Shetu, see CHANGES.md` header; `src-tauri/src/storage/ftp/LICENSE-APACHE` (upstream license text) and `CHANGES.md` (one line per change below) ship with them.
- Connection cap: **2** per account. Upload temp name: `.<name>.shetu-<random>` in the target's folder.
- Error copy, verbatim:
  - AUTH TLS refused: "This server doesn't support FTPS; choose FTP (unencrypted) if you trust the network."
  - Missing starting folder: "<folder> doesn't exist on the server"
- No password in logs, errors or `Debug`.
- `rustfmt --edition 2021` on touched files only (never `cargo fmt`, never on `lib.rs`); `biome check --write` on touched files only.

## Review Focus

- A server whose `LIST -a` fails (treats `-a` as a path) and lacks MLSD: listing falls back to plain `LIST` (Task 3 test `list_falls_back_to_plain_list`).
- Replacing a file on a server that refuses `RNTO` onto an existing name: delete the target, then rename (Task 4 test `replace_deletes_then_renames`).
- The starting folder removed mid-session: the next connection fails with the missing-folder error and never sends `MKD` (Task 2 test `missing_root_is_an_error_not_created`).
- Three transfers plus browsing on one account: never more than 2 server connections (Task 2 test `pool_never_exceeds_two_connections`).
- An FTPS account on a server that refuses `AUTH TLS` never falls back to plain FTP (Task 6 test `ftps_never_falls_back_to_plain`).
